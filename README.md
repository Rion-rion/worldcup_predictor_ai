# ⚽ ワールドカップ予想AI

代表戦データ、Eloレーティング、選手データ、機械学習、モンテカルロシミュレーションを活用し、サッカー代表戦の勝敗・スコア分布・グループリーグ突破確率を予測するAIプロジェクトです。

Python / Visual Studio Code 環境で動作し、日本対オランダなど任意の代表戦を対象に、

* 勝敗確率の予測
* 期待得点の算出
* 1万回の試合シミュレーション
* スコア分布の算出
* グループリーグ順位予測
* グループリーグ突破率の算出
* 試合ログ生成

を行います。

---

# 📌 プロジェクト概要

このプロジェクトでは、過去の国際Aマッチの試合結果と選手データを組み合わせ、サッカー代表チームの試合結果を予測します。

代表チームの強さをEloレーティングで数値化し、直近5試合・10試合の成績や選手能力などを特徴量として利用します。

機械学習モデルによる勝敗予測に加え、ポアソン分布を用いたモンテカルロシミュレーションによって、実際のサッカーのような確率的な試合結果を生成します。

# 🤖 主な機能

## 1. 勝敗予測AI

過去の代表戦データを利用して、試合結果を以下の3クラスに分類します。

```text
0 = ホームチーム敗北
1 = 引き分け
2 = ホームチーム勝利
```

使用モデル：

```text
RandomForestClassifier
```

主な特徴量：

* ホームチームElo
* アウェイチームElo
* Elo差
* Elo期待勝率
* 直近5試合勝率
* 直近10試合勝率
* 直近5試合平均得点
* 直近10試合平均得点
* 直近5試合平均失点
* 直近10試合平均失点
* チーム力
* 中立地開催フラグ

これらの特徴量から、

* ホーム勝利確率
* 引き分け確率
* アウェイ勝利確率

を算出します。

---

# 🎲 2. 試合シミュレーション

Eloレーティング・チーム力・過去の得点傾向などから、それぞれのチームの期待得点を算出します。

算出した期待得点をポアソン分布に入力し、1試合につき10,000回のシミュレーションを実行します。

### 出力例

```text
日本勝利確率       27.35%
引き分け確率       25.19%
オランダ勝利確率   47.46%

日本期待得点       1.08
オランダ期待得点   1.52
```

さらに、

* 0-0
* 1-0
* 1-1
* 1-2
* 2-1
* 2-2

など、それぞれのスコアが発生する確率も計算します。

---

# 🏆 3. グループリーグ突破率予測

グループ内の全対戦カードを繰り返しシミュレーションし、各国の順位確率を算出します。

現在のテスト対象グループ：

* 🇯🇵 日本
* 🇳🇱 オランダ
* 🇹🇳 チュニジア
* 🇸🇪 スウェーデン

各国について、

* 1位通過確率
* 2位以内突破確率
* 平均勝ち点

を算出します。

### 出力例

| 国      |   1位確率 | 2位以内突破確率 | 平均勝ち点 |
| ------ | -----: | -------: | ----: |
| オランダ   | 41.79% |   69.92% |  5.21 |
| スウェーデン | 25.38% |   52.75% |  4.29 |
| 日本     | 21.95% |   48.61% |  4.01 |
| チュニジア  | 10.88% |   28.72% |  2.96 |

※数値はシミュレーション条件によって変化します。

---

# 📝 4. 試合ログ生成

選手スコアやチーム力を利用して、試合の流れを1分単位でシミュレーションします。

```text
31分 オランダ ゴール
45分 前半終了
57分 日本 チャンスメイク

```

将来的には選手名やポジションも利用し、より現実的な試合展開を生成する予定です。

# 💡 工夫した点

## Eloレーティングの実装

代表チームの強さを比較するため、過去の試合結果からEloレーティングを計算しています。

単純なFIFAランキングだけではなく、実際の対戦結果からチーム力を更新できます。

---

## 直近5試合・10試合の両方を利用

直近5試合と10試合の成績を特徴量として利用することで、

```text
5試合 → 最近の調子
10試合 → 中期的なチーム状態
```

の両方をモデルに反映します。

---

## 選手データをチーム力に反映

代表戦結果だけでなく、

* 市場価値
* 出場時間
* 得点
* アシスト

などを利用し、選手個人の能力をチーム力として数値化しています。

---

## 10,000回シミュレーション

1回の予測結果だけで勝敗を決定するのではなく、同じ試合を10,000回シミュレーションします。

これにより、

```text
日本勝利 27%
引き分け 25%
オランダ勝利 48%
```

のような確率として試合結果を表現できます。

---

## グループリーグ全体を予測

1試合の勝敗だけではなく、グループ内の全対戦カードをシミュレーションします。

これによって、

* 各国の平均勝ち点
* 1位通過確率
* 2位以内突破確率

まで算出できます。

# ⚠️ 現在の課題

現在のモデルには以下の課題があります。

* 公式代表メンバーではなく国籍ベースで選手を抽出している
* 実際のスターティングメンバーを反映していない
* 怪我人を反映していない
* 出場停止選手を反映していない
* 監督や戦術の違いを反映していない
* FIFAランキング・FIFAポイントを使用していない
* 引き分け予測の精度が低くなりやすい
* 選手ポジション分類がデータセットに依存している
* 市場価値が高い選手に評価が偏る可能性がある
* 大会の重要度による違いを十分に反映していない
