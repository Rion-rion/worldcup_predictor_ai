# World Cup Predictor AI

代表戦データ、Eloレーティング、選手データを活用して、サッカー代表戦の勝敗・スコア分布・グループリーグ突破確率を予測するAIプロジェクトです。

Google Colab上で動作し、日本 vs オランダなど任意の代表戦を対象に、試合結果の確率予測、1万回シミュレーションによるスコア分布、グループリーグ突破率、試合ログ生成を行います。

## 概要

このプロジェクトでは、過去の国際Aマッチ結果と選手データを組み合わせ、サッカー代表戦の結果を予測します。

主な処理は以下です。

* 代表戦データの取得
* 選手データの取得
* 選手市場価値・出場時間・得点・アシストを用いた選手スコア算出
* 国別チーム力の算出
* Eloレーティングの計算
* 直近5試合・10試合の成績特徴量作成
* RandomForestによる勝敗予測AIの学習
* ポアソン分布によるスコアシミュレーション
* グループリーグ突破率の算出
* 1分ごとの試合ログ生成

## 使用データ

このプロジェクトでは、以下のデータを使用しています。

### 代表戦データ

国際Aマッチの試合結果データを使用し、勝敗・得点・失点・直近成績・Eloレーティングを作成しています。

### 選手データ

Kaggleの選手データを使用し、以下の情報から選手スコアを作成しています。

* 市場価値
* 出場時間
* 得点
* アシスト
* 年齢
* 国籍
* ポジション

## 主な機能

### 1. 勝敗予測AI

過去の代表戦データから、以下の3分類を予測します。

* ホーム負け
* 引き分け
* ホーム勝ち

特徴量には、Eloレーティング、直近5試合・10試合の勝率、平均得点、平均失点などを使用しています。

### 2. 試合シミュレーション

チーム力から期待得点を算出し、ポアソン分布を使って試合を1万回シミュレーションします。

出力例：

* 日本勝利確率
* 引き分け確率
* オランダ勝利確率
* 期待得点
* 最頻スコア
* スコア分布

### 3. グループリーグ突破率予測

グループ内の全対戦カードをシミュレーションし、各国の以下の確率を算出します。

* 1位通過確率
* 2位以内突破確率
* 平均勝ち点

### 4. 試合ログ生成AI

選手スコアをもとに、1分ごとの試合展開を生成します。

例：

* パス
* チャンスメイク
* シュート
* ゴール
* 試合終了結果

## 工夫した点

* Eloレーティングを自作して代表チームの強さを数値化
* 直近5試合と10試合の両方を特徴量にして、短期調子と中期成績を反映
* 選手の市場価値・出場時間・得点・アシストから選手スコアを作成
* チーム力をもとに期待得点を算出
* 1試合だけでなく、1万回のシミュレーションで確率的に結果を算出
* グループリーグ全体の突破率まで計算
* 日本語表示・グラフ表示に対応
* データ列名の違いや重複列エラーにも対応

## 現在の課題

* 公式代表メンバーではなく、国籍ベースで選手を抽出している
* 実際のスタメン、怪我、出場停止、監督戦術は反映していない
* 引き分け予測の精度が低くなりやすい
* FIFAランキングや最新の代表チーム状況は未反映
* 選手ポジションの分類がデータ依存になっている
* 市場価値が高い選手に評価が寄りやすい
